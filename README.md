# Commonplace

A Markdown-first personal knowledge space for notes, moodboards and, reminders.

## Project status

Pre-planning. The repository is intentionally starting from an empty state; no application framework or platform commitment has been made yet.

## Product and business direction

Commonplace is being planned as a personal. Markdown-first workspace for notes, reminders, visual organization, and small-group sharing. Its eventual business model is undecided; a paid app is strongly considered if sync is reached.

## Product direction

Commonplace treats Markdown files as the durable source of truth, uses a live-rendering editor with a spatial desktop canvas, and aims to keep data portable and under the user's control.
